# Laboratory 05 - Hydrogen Atom Wavefunctions via Metropolis Algorithm

This directory contains the C++ implementation and data analysis for the fifth laboratory session, focusing on the estimation of the mean radius of the Hydrogen atom in its ground state (1s) and first excited state (2p). It utilizes the Metropolis algorithm to sample the spatial probability density functions in Cartesian coordinates, evaluating both uniform and Gaussian transition probabilities.

## Project Structure
- `src/exercise05-1.cpp`: Main source file for the Metropolis simulation and Data Blocking evaluation of the expectation value of the radius.
- `src/autocorrelation/autocorr_generator.cpp`: C++ program that generates raw, unequilibrated Metropolis steps to study the memory of the Markov chain.
- `src/autocorrelation/pipeline.py`: Python orchestration script that automates raw data generation, calculates the burn-in phase, extracts the autocorrelation time ($\tau_c$), and exports the optimal simulation parameters.
- `src/autocorrelation/config.txt`: Configuration file automatically generated by the Python pipeline and read by the main C++ simulation.
- `../utils/metropolis/`: Object-oriented implementation of the Metropolis algorithm, featuring automated step tuning and equilibration.
- `../utils/data_blocking/`: Object-oriented implementation of the data blocking method for statistical uncertainty estimation.
- `../utils/random/`: Specialized library for random number generation (provided).
- `../utils/auxiliary_functions/`: Custom helper functions.
- `analysis5.ipynb`: Jupyter Notebook containing the main data analysis, 3D scatter plots of the sampled orbitals, and theoretical comparisons.
- `Makefile`: Automated build system for compilation and execution.

## Compilation and Usage
The project uses a hidden `.build/` directory to store object files and executables, keeping the root directory clean. 

**Important:** The main simulation dynamically reads its execution parameters from `config.txt`. You must execute the autocorrelation pipeline before running the main C++ program.

### 1. Autocorrelation Pipeline
Navigate to the autocorrelation directory and run the Python pipeline to generate the configuration file and the diagnostic plots:

```bash
cd src/autocorrelation
python pipeline.py
cd ../../
```

### 2. Build
To compile the C++ exercises:

```bash
make
```

### 3. Execution
To run the main Metropolis simulation (requires `config.txt` to be present):

```bash
make run
```

## Clean Up
To remove the hidden `build/` directory and generated seed files:

```bash
make clean
```

## Data Analysis
The simulation results are processed in the `analysis5.ipynb` notebook. The analysis visually reconstructs the 3D shapes of the 1s and 2p orbitals and compares the progressive Monte Carlo estimates of the mean radius (with statistical uncertainties calculated via data blocking) against the exact quantum mechanical expectations. The diagnostic plots regarding system thermalization and the exponential fit of the autocorrelation function are generated directly by the Python pipeline.

## Disclaimer regarding directory size:
Please note that this directory is significantly large. The majority of the size comes from the generated `.dat` output files, which track the 3D spatial coordinates for over 1,000,000 Monte Carlo steps across multiple configurations, as well as the high-resolution `.png` images generated for the autocorrelation and equilibration analysis.
